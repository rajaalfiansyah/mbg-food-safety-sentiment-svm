# Public Sentiment Analysis on Free Nutritious Meal Program Incidents (SVM)

An NLP-driven Machine Learning web application designed to analyze and classify public social media sentiment surrounding mass food poisoning incidents linked to Indonesia's 2025 Free Nutritious Meal Program (MBG) using the Support Vector Machine (SVM) classification algorithm.

## ✨ Key Features
- **Text Preprocessing Pipeline:** Automatic text cleaning, case folding, tokenization, stopword removal, and stemming.
- **Feature Extraction:** TF-IDF (Term Frequency-Inverse Document Frequency) text vectorization.
- **SVM Classifier Engine:** High-accuracy sentiment classification into positive, negative, and neutral categories using Support Vector Machine.
- **Analytics Dashboard:** Real-time visual sentiment breakdown, confusion matrix evaluation, and topic word clouds.

## 🛠️ Tech Stack
- **Frontend / Web:** React, TypeScript, Tailwind CSS
- **Machine Learning & NLP:** Support Vector Machine (SVM), TF-IDF Vectorizer
- **Deployment:** Vercel & GitHub
